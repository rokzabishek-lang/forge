- Fade grips and the volume envelope are both directly on the clip and correctly layered against the drag/trim gestures underneath: FadeHandles.tsx:42-50 and VolumeEnvelope.tsx:144-174 (transparent fat stroke for hit testing, container with `pointer-events-none`). The comment at VolumeEnvelope.tsx:94-107 records that an earlier version ate every other clip gesture. This is CapCut/Resolve-grade direct manipulation, not a panel of number fields.
- SFX from the library are genuinely auditionable before placement: clicking one plays it and loads it into the trimmer (src/renderer/src/components/Library.tsx:399-410), the waveform trims it in source time (src/renderer/src/components/Waveform.tsx:19-23), and `addAuditionToTimeline` (src/renderer/src/store.ts:1233) imports only the chosen range at the playhead. That is better than CapCut, where an SFX lands whole and you trim it after.
- Sample-rate handling is correct by construction: every clip is forced through `aformat=...channel_layouts=stereo` and `aresample=${project.settings.sampleRate}` before anything else (src/shared/render/plan.ts:1376-1377), the project rate is 48000 (src/shared/timeline.ts:660), and the silent-fallback `anullsrc` uses the same rate (plan.ts:1479). Mixed 44.1/48 kHz sources — the normal case when stock music meets phone footage — cannot produce a pitched or desynced mix.

### media-project-export
- Export is a real background job, not a modal wait. `render:start` queues into `JobQueue` (src/main/queue.ts:31-179) which runs it with live progress, ffmpeg's own speed string, per-job cancel, and a 'Show in folder' button on completion (src/renderer/src/components/Inspector.tsx:1463-1520). You can keep editing while it encodes, and queue several. CapCut's desktop export is a blocking modal; this is Premiere/Resolve behaviour.
- Cancel actually leaves nothing broken behind. `runFfmpeg` rejects only from the unlink's continuation, so 'this job ended' means the truncated file is already gone (src/main/ffmpeg/run.ts:130-157), and `killProcess` uses `taskkill /f /t` on Windows and a process-GROUP kill on POSIX so yt-dlp's child ffmpeg cannot survive the cancel (src/main/ffmpeg/run.ts:36-75). Most Electron wrappers leave a half-written mp4 and an orphan process.
- Loudness normalisation is a first-class export property, measured on the finished mix after the ducking and the music join it (src/shared/render/plan.ts:1481-1499), with LUFS targets on the Output panel (src/renderer/src/components/Inspector.tsx:300-345). In Premiere this is a separate Loudness Radar pass and a manual gain adjustment; CapCut does not expose it at all.
- The draft-export toggle halves the canvas for a measured ~4x speedup and is honest about what it is for (src/renderer/src/components/Inspector.tsx:186-200, 617-643). Resolve's 'proxy/optimised media' is the nearest equivalent and takes far more setup.
- The whole render is one pure function from Timeline IR to argv (src/shared/render/plan.ts:32-44), so the export path is unit-testable without spawning anything — and it is actually tested against the real bundled binary (tests/integration/compositor.int.test.ts, kenburns.int.test.ts, captionOverlay.int.test.ts, filterPath.int.test.ts and ~20 more).
- Packaging is genuinely solved rather than aspirational: binaries are asar-unpacked (electron-builder.yml:46-56) and `assertBinaries()` fails loudly at startup instead of on the first job (src/main/ffmpeg/paths.ts:26-48), with a `tests/packaging.test.ts` guarding it.
- The project format is versioned with a migration hook and refuses a file from a newer build with a readable message instead of half-loading it (src/shared/project.ts:24, 72-88), and unknown fields survive a round trip. Premiere project files are notoriously one-way; this is better discipline.
- Import-by-URL is wired into the same queue as exports, with clipping a range before the download (src/main/ipc.ts:906-988). No other NLE on this list gets media in from a link at all.
- The `forge-media` protocol is registered with `stream: true` specifically so HTTP range requests work and scrubbing a long source in the preview is possible (src/main/index.ts:15-36) — the thing most Electron editors get wrong and then ship with a preview that cannot seek.
- A cancelled or superseded generated-asset bake cannot corrupt a clip's frame sequence (src/shared/bakeGuard.ts:26-66), which is a class of silent corruption the big NLEs also have and mostly handle by locking the UI.

### effects-color-text
- Keyframes are genuinely end-to-end and the preview evaluates the SAME curve the export compiles, so they cannot drift: the UI writes keys (src/renderer/src/components/Keyframes.tsx:63-103), the preview calls `valueAt` per frame (src/renderer/src/components/Preview.tsx:828-830), and the export compiles the identical key list into an ffmpeg expression (src/shared/render/plan.ts:312-318, 366-408, 435). Easing (linear/smooth/hold) exists on each key and both halves agree at the key frame (src/shared/render/keyframes.ts:81-123). Most NLE clones fake the preview.
- A real, dual-mode curve editor: a motion curve with point-drag AND freehand sketching reduced to keys (src/renderer/src/components/CurveEditor.tsx:85-113, 246-274), and an RGB+master grading curve drawn with the natural cubic spline ffmpeg actually applies rather than straight segments (src/renderer/src/components/ColourCurve.tsx:14-24, 95-98), both in a wide panel next to the timeline (src/renderer/src/components/CurvePanel.tsx:41-110). Resolve-grade affordance; CapCut has no freehand motion curve at all.
- Grade order matches Resolve/CapCut and is honoured in both paths: eq sliders, then curves, then LUT at an intensity (src/shared/timeline.ts:134-179; src/shared/render/plan.ts:959, 1038, 1190). Built-in looks are shipped and written to disk on first use, with 'load your own .cube' still offered (src/renderer/src/components/Inspector.tsx:82-84, 866-897).
- Masks are a shape AND a verb — blur / grade / reveal — with feather, invert, width/height, angle, draggable on the picture, and the grade sliders correctly scoped to inside the shape (src/renderer/src/components/MaskPanel.tsx:29-186; Inspector.tsx:808-818). CapCut's mask is reveal-only; a blur-inside-inverted-shape is a first-class thing here.
- Text is three independent axes — typography preset, paint style, arrival animation — multiplying rather than adding (src/renderer/src/components/Inspector.tsx:923-985), with 24+ styles including gradient/glow/metallic/boxed (src/shared/render/textStyle.ts:164, 483-598) and animation chips that actually PLAY in the user's own font and words (src/renderer/src/components/TextAnimationPicker.tsx:11-23). Outline, stroke colour, tracking, weight, shadow, CAPS and free offset are all wired (Inspector.tsx:1040-1105; src/shared/timeline.ts:401-475).
- Fonts are a real library: 80+ bundled families plus SYSTEM-installed fonts, lazily registered per visible row so the picker does not stall, with restricted-licence flagging (src/renderer/src/components/FontPicker.tsx:49-65, 131-140). Both captions and text cards reach it (Inspector.tsx:447-479, 987-1017).
- Adjustment layers exist as a real Resolve-style clip that grades everything beneath it instead of drawing (src/shared/timeline.ts:377-385; src/renderer/src/store.ts:2368-2412; src/shared/render/plan.ts:1017-1024; src/renderer/src/components/Preview.tsx:1074-1085) — Resolve and Premiere have this, CapCut desktop does not.
- Clip stickers are properly composited, not overlaid green: the keyed cut-out ships as a colour+alpha pair and goes through alphamerge on the same footing as any other shape, so a sticker can also be masked or wiped (src/shared/render/plan.ts:1134-1154; src/renderer/src/components/Preview.tsx:130-138), and they land muted by design (plan.ts:1366).
- Transitions are not eight presets: 400+ mask wipes on top of the built-ins, grouped by family AND tagged by what the mask's own pixels DO (grid, blinds, wipes), with a visible failure state when the library does not load (src/renderer/src/components/Inspector.tsx:1336-1400). Also correctly offered between LAYERED clips, not just same-track cuts (Inspector.tsx:160-168; src/shared/timeline.ts:1000-1008).
- Speed is honest about its own physics: presets always enabled, a rate slider, an explicit 'smooth slow motion' toggle whose tooltip states the measured 41x render cost, and the new clip length said out loud (src/renderer/src/components/SpeedPanel.tsx:46-101).
- The Toolbox refuses to ship a button that silently does nothing — the unbuilt Paint tool is greyed, below a rule, and says 'stills only, and a long way off' on hover (src/renderer/src/components/Toolbox.tsx:195-223).

### first-hour
- Every automation writes ordinary, labelled, reversible clips — `generatedBy.reason` is shown back to the user (`src/renderer/src/components/Automation.tsx:865-879`), Clear removes exactly that rule's output (`clearReel`/`clearGrid`/`clearStrips`/`clearDirectorOutput`, wired at `Automation.tsx:54,81,98` and `Director.tsx:48`), and the Director's whole placement is ONE undo step. No other NLE's AI features are auditable or cleanly reversible like this — CapCut's auto-cut and Premiere's Text-Based Editing both hand you a result you cannot un-apply as a unit.
- The Director is a genuine brief-to-timeline path with an honest failure mode: it validates the model's plan, falls back to a standard cut, and SAYS which one you got plus the model's notes (`src/renderer/src/components/Director.tsx:351-378`, `last.baseline ? 'Standard cut' : 'Directed by ...'`). Nothing in CapCut/Premiere/Resolve tells you the automation degraded.
- No per-use cost and a real local-model story: Auto / Ollama / any OpenAI-shaped server, with model discovery, a live readiness dot and reason text, and a write-only API key field (`src/renderer/src/components/Director.tsx:244-332`). Competitors' AI features are all metered cloud calls.
- Unbuilt things are visibly unbuilt rather than silently inert — the Paint tool is disabled with `soon: 'stills only, and a long way off'` and a rule drawn above it (`src/renderer/src/components/Toolbox.tsx:196-205,223`), and the Narration source says exactly what it will do (`src/renderer/src/components/SourceBar.tsx:43`).

This is the single most common way CapCut-grade tools feel broken, and it is deliberately fixed here.
- The orientation warning is a standing banner with a one-click fix rather than a toast (`src/renderer/src/components/Automation.tsx:140-158,342-356`) — a marketer who imports portrait phone photos into the 16:9 default is told, and given `Switch the canvas to 9:16`.
- Draft export is a measured 4x, not a guess (`src/renderer/src/components/Inspector.tsx:186-199,612-633`), and the render job list gives progress, encode speed, cancel and Show-in-folder (`Inspector.tsx:1464-1520`).
- Timeline clip drag moves in both axes at once — time and layer — with a same-kind/not-locked guard that keeps the horizontal move alive when the vertical one is refused (`src/renderer/src/components/Timeline.tsx:228-241`). Resolve and Premiere do this; CapCut desktop largely does not.
